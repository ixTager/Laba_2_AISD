# Кастомная реализация алгоритма Timsort на C++

Репозиторий содержит лабораторную работу по дисциплине «Алгоритмы и структуры данных», в которой реализован гибридный алгоритм сортировки **Timsort**. Главная особенность проекта — **полный отказ от контейнеров STL** в пользу собственных шаблонных структур данных.

## 🛠 Архитектура и структура проекта

Проект разбит на логические модули (заголовочные файлы), каждый из которых отвечает за строго определенную структуру данных или этап алгоритма:

### 1. Собственные структуры данных (Замена STL)
*   **`DynamicArray.h`** — Шаблонный динамический массив (аналог `std::vector`), реализующий автоматическое реаллоцирование памяти при расширении, индексацию и базовые методы работы с элементами.
*   **`Stack.h`** — Шаблонный стек (аналог `std::stack`), необходимый для хранения метаданных о запущенных последовательностях (`run`). Используется для контроля инвариантов слияния.

### 2. Компоненты алгоритма Timsort
*   **`Run.h`** — Модуль для работы с подмассивами. Отвечает за инкапсуляцию структуры `Run` (хранит индекс начала и длину подмассива), поиск упорядоченных последовательностей во входном массиве, а также за разворот строго убывающих последовательностей.
*   **`InsertionSort.h`** — Реализация сортировки вставками. Применяется локально для сортировки элементов внутри `run`, если его длина оказалась меньше вычисленного значения `minrun`.
*   **`MergeSort.h`** — Логика слияния двух соседних упорядоченных подмассивов (левого и правого) с выделением временной памяти под меньший из них для обеспечения стабильности сортировки.
*   **`TimSort.h`** — Сердце проекта. Главный управляющий класс, который:
    1. Вычисляет оптимальный `minrun` на основе побитовых операций.
    2. Итерируется по массиву, выделяя `run` и досортировывая их вставками.
    3. Поддерживает инварианты стека ($Z > Y + X$ и $Y > X$) и запускает слияние через `MergeSort`.

### 3. Точка входа
*   **`Laba_2_AISD.cpp`** — Содержит функцию `main`, демонстрационные тесты, генерацию входных массивов (включая частично отсортированные, случайные и инвертированные данные) и замер времени работы алгоритма.

## 🚀 Особенности реализации

*   **Шаблонные классы (Templates):** Все структуры данных (`DynamicArray`, `Stack`) и алгоритмы реализованы как шаблоны, что позволяет сортировать массивы любых типов данных, поддерживающих операторы сравнения (`<`, `>`, `<=`, `>=`).
*   **Управление памятью:** Выделение и освобождение памяти контролируются вручную внутри классов структур данных, что исключает утечки памяти при работе алгоритма.
*   **Эффективный расчет minrun:** Реализована каноническая функция сдвига битов для быстрого определения базового размера подмассива.

## 💻 Сборка проекта

Проект подготовлен в виде решения для **Microsoft Visual Studio**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `Laba_2_AISD.sln` в Visual Studio.
3. Выберите конфигурацию `Release` и архитектуру `x64` (для более точных замеров скорости).
4. Запустите сборку и выполнение проекта (Ctrl + F5).
